مدقق JSON

تحقق من صحة JSON واكتشف أخطاء الصياغة.

تعمل الأداة داخل متصفحك ولا تتطلب تسجيل دخول.
ملاحظات عملية
يفحص المدقّق صحة صياغة JSON مثل الأقواس والفواصل وأنواع القيم. نجاح الفحص لا يعني أن البيانات تطابق مخطط عملك أو أن الحقول المطلوبة موجودة؛ لذلك استخدم JSON Schema أو قواعد التطبيق للتحقق الدلالي. يتم التحليل محليًا وتظهر رسالة الخطأ لتحديد موضع المشكلة.

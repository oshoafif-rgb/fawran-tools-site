أدوات المواقع

فحص سرعة الموقع وأدوات SEO التقنية للمواقع.

مولد Favicon وأيقونة الموقع

أنشئ favicon احترافيًا للموقع بكل المقاسات المطلوبة للمتصفح والجوال مع كود HTML جاهز.

مولد Meta Tags

أنشئ Title وMeta Description وOpen Graph وTwitter Cards لتحسين ظهور صفحاتك في محركات البحث والمشاركة.

صانع صور Open Graph

أنشئ صورة مشاركة 1200×630 احترافية لفيسبوك وX وواتساب وباقي المنصات.

مولد Redirect 301 وNginx

أنشئ قواعد إعادة توجيه 301 لـ Apache وNginx بطريقة مناسبة لـ SEO.

مولد robots.txt

أنشئ ملف robots.txt صحيحًا لمحركات البحث مع Sitemap وقواعد Allow وDisallow.

مولد Schema وJSON-LD

أنشئ Structured Data وSchema JSON-LD للمقالات والمنتجات والأسئلة لتحسين فهم محركات البحث للمحتوى.

مولد Sitemap XML

أنشئ ملف sitemap.xml من روابط موقعك لمساعدة محركات البحث على اكتشاف الصفحات.

فحص سرعة الموقع

اختبر سرعة الموقع ومؤشرات Core Web Vitals باستخدام بيانات PageSpeed الرسمية.

محول أسعار العملات

حوّل بين أكثر من 200 عملة عالمية بأسعار صرف محدّثة يوميًا.

منشئ ودجت أسعار العملات

أنشئوا ودجت أسعار صرف حي لموقعك مع كود جاهز للصق.

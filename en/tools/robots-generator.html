How to use robots.txt generator step by step

Follow these steps to get a reliable result from robots.txt generator, checking both the inputs and output before saving or publishing.

  1. 1

    Add the inputs

    Enter the URL, HTML, or requested data exactly as it appears on the live page.

  2. 2

    Adjust the options

    Adjust available settings such as “Sitemap URL”, “Disallowed paths (one per line)”, “Explicitly allowed paths (optional)” for the result you need. Start with the defaults, then refine them after previewing.

  3. 3

    Run the tool

    Run robots.txt generator after completing the inputs, then wait for the result or analysis report to appear on the page.

  4. 4

    Review and save the result

    Review the preview or report, then use “Copy the code” or “Download robots.txt” to save the result. Keep the original file for comparison or recovery.

Tips for the best result

Test generated code or files in a staging environment before applying them to a live website. Core processing for this tool runs in the browser; still, keep an original copy of important files.

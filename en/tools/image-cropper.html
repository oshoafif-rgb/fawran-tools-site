Practical guide

How to use Crop images step by step

Follow these steps to get a reliable result from Crop images, checking both the inputs and output before saving or publishing.

  1. 1

    Add the inputs

    Upload the required image or images and confirm that the format and size suit the task before processing.

  2. 2

    Adjust the options

    Review values, format, and order before running the tool. Use realistic, non-sensitive data so the result can be evaluated accurately.

  3. 3

    Run the tool

    Run Crop images after completing the inputs, then wait for the result or analysis report to appear on the page.

  4. 4

    Review and save the result

    Review the preview or report, then use “Crop and download” to save the result. Keep the original file for comparison or recovery.

Tips for the best result

Compare quality and file size after export, and verify transparency and dimensions before using the image in a site or campaign. Core processing for this tool runs in the browser; still, keep an original copy of important files.

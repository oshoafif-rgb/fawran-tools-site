Email Validator

Check whether a single email address or an entire list is correctly formatted — format only, no actual message is sent.

Important note: This tool only checks the spelling/format (presence of @, a valid domain, etc.) — it does not confirm the email is actually active or exists, since that would require sending a real verification message.
Practical guide

How to use Email Validator step by step

Follow these steps to get a reliable result from Email Validator, checking both the inputs and output before saving or publishing.

  1. 1

    Add the inputs

    Enter the email address, list, or signature details, placing each value in its designated field.

  2. 2

    Adjust the options

    Adjust available settings such as “Paste one email or a list (one per line)”, “Detailed result” for the result you need. Start with the defaults, then refine them after previewing.

  3. 3

    Run the tool

    Select “Check now” and wait for processing to finish. Check any status messages or warnings before using the result.

  4. 4

    Review and save the result

    Review the result for unexpected values, then copy or save the output using the option provided by the tool.

Tips for the best result

Avoid confidential customer lists, and test links or signatures in a draft message before a bulk send. Core processing for this tool runs in the browser; still, keep an original copy of important files.

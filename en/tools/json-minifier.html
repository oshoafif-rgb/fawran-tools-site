JSON Minifier

Minify JSON by removing unnecessary whitespace.

Runs in your browser. No login required.

Practical notes

Minification removes unnecessary whitespace and line breaks from valid JSON, but it is not compression like Gzip and does not rename keys. Keep a formatted copy for development and review, and use the compact version for transport when useful. The input must parse successfully before a minified result can be produced.

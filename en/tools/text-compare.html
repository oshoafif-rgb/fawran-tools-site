Practical guide

How to use Compare texts step by step

Follow these steps to get a reliable result from Compare texts, checking both the inputs and output before saving or publishing.

  1. 1

    Add the inputs

    Paste the text or code you want to process, preserving its original formatting when needed.

  2. 2

    Adjust the options

    Adjust available settings such as “Original text”, “New text” for the result you need. Start with the defaults, then refine them after previewing.

  3. 3

    Run the tool

    Run Compare texts after completing the inputs, then wait for the result or analysis report to appear on the page.

  4. 4

    Review and save the result

    Review the result for unexpected values, then copy or save the output using the option provided by the tool.

Tips for the best result

Review punctuation and formatting after processing, especially in multilingual text. Core processing for this tool runs in the browser; still, keep an original copy of important files.

Sitemap Generator (Sitemap.xml)

Paste one URL per line, choose the default change frequency and priority, and generate a valid sitemap.xml file for your site.

All processing takes place locally in your browser — your links are not sent to any server

Practical guide

How to use Sitemap Generator (Sitemap.xml) step by step

Follow these steps to get a reliable result from Sitemap Generator (Sitemap.xml), checking both the inputs and output before saving or publishing.

  1. 1

    Add the inputs

    Enter the URL, HTML, or requested data exactly as it appears on the live page.

  2. 2

    Adjust the options

    Adjust available settings such as “Default update frequency”, “Default priority”, “The first link (home) is automatically prioritized at” for the result you need. Start with the defaults, then refine them after previewing.

  3. 3

    Run the tool

    Select “Generate sitemap” and wait for processing to finish. Check any status messages or warnings before using the result.

  4. 4

    Review and save the result

    Review the preview or report, then use “Download sitemap.xml” or “Copy the code” to save the result. Keep the original file for comparison or recovery.

Tips for the best result

Test generated code or files in a staging environment before applying them to a live website. Core processing for this tool runs in the browser; still, keep an original copy of important files.

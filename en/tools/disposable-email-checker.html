Disposable Email Checker

Check a single email or a full list against known temporary email domains (like Mailinator, Guerrilla Mail, and others).

Note: The list covers over 100 common temporary domains, but new disposable email services with new domains appear constantly, so no list can ever be 100% exhaustive.
Practical guide

How to use Disposable Email Checker step by step

Follow these steps to get a reliable result from Disposable Email Checker, checking both the inputs and output before saving or publishing.

  1. 1

    Add the inputs

    Enter the email address, list, or signature details, placing each value in its designated field.

  2. 2

    Adjust the options

    Adjust available settings such as “Paste one email or a list (one per line)”, “Result” for the result you need. Start with the defaults, then refine them after previewing.

  3. 3

    Run the tool

    Select “Check now” and wait for processing to finish. Check any status messages or warnings before using the result.

  4. 4

    Review and save the result

    Review the result for unexpected values, then copy or save the output using the option provided by the tool.

Tips for the best result

Avoid confidential customer lists, and test links or signatures in a draft message before a bulk send. This tool needs an external service to complete the check or retrieve data, so do not enter private URLs or confidential data.

URL Encoder & Decoder

Encode and decode URLs and text.

Runs in your browser. No login required.

Practical notes

Encode individual URL components such as a query value rather than blindly encoding an entire URL, which may escape structural characters like : and /. Decoded text can still be untrusted, so never execute it as code. The conversion runs locally using the browser's standard URL-encoding functions.

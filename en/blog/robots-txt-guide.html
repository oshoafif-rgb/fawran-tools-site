What is robots.txt and how it controls Google crawling your site

Article content:

  • What exactly is robots.txt?
  • Understanding the basic file structure
  • The most dangerous mistake: accidentally blocking the entire site
  • How to create a correct robots.txt file?
  • Frequently Asked Questions

A small file with just two or three lines, but if written incorrectly it can prevent Google from indexing your entire website without you noticing. The robots.txt file is almost the first file that search engine bots visit when they reach your site, and it tells them what is allowed to be crawled and what is forbidden. In this guide, we will safely explain everything about it.

What exactly is robots.txt?

robots.txt is a simple text file placed at the root of your website, containing instructions for search engine robots (like Googlebot) about which parts of Website they are allowed to crawl and which parts are restricted. The file does not prevent the page from being accessed by regular users — it is only directed at automated robots and relies on their voluntary compliance (major search engines like Google respect it, but not all robots comply).

Understanding the basic file structure

User-agent: * Disallow: /admin/ Disallow: /private/ Allow: / Sitemap: https://example.com/sitemap.xml

User-agent: Specifies which robot the rule applies to (* means all robots). Disallow: Prevents crawling of a specific path. Allow: Explicitly allows crawling (useful to exclude a subfolder inside a forbidden folder). Sitemap: It points to the link of your sitemap to make it easier to discover.

The most dangerous mistake: accidentally blocking the entire site

User-agent: * Disallow: /

These two lines prevent crawling Full Website — a very common mistake, especially if a robots.txt file is copied from a staging environment to the live site by accident without modification. If your site does not appear on Google even though you did everything correctly, the first thing to check is the content of your robots.txt file.

Frequently Asked Questions

Does robots.txt prevent a page from appearing on Google completely?

Not necessarily, robots.txt prevents crawling but does not necessarily prevent indexing. A blocked page may appear in search results without a description if it is linked from other pages.

Where should the robots.txt file be placed?

Directly in the root folder of your site, to be available at the link yoursite.com/robots.txt exactly.

What happens if my site doesn’t have a robots.txt file?

In the absence of the file, search engine robots usually assume that all pages of Website are allowed to be crawled, which is the safe default behavior.

Should I add a sitemap link inside robots.txt?

Yes, it is recommended to add a Sitemap line pointing to Websitemap.xml file link, because this helps search engines discover the map more easily.

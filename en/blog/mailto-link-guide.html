Mailto link: How to make a "Contact Us" button open an email with a ready subject.

The "Contact Us" button that opens the mail program directly, with the subject and text ready, saves a lot of steps for your website visitor. The technical solution behind this button is very simple and available to anyone, without any complex programming code.

What is a mailto link?

A mailto link is a special type of link that starts with "mailto:" instead of "https://", and when you click on it, it opens the default email program on your device (like Outlook or Apple Mail) instead of opening a web page. You can add extra data to the link to automatically fill in message fields before the user starts typing.

The data you can control

  • To: Primary recipient address.
  • CC (Carbon Copy): Additional recipients visible to all.
  • BCC (blind copy): Additional recipients not visible to other recipients.
  • Subject: The message title is pre-made.
  • Body: Default message content, editable before sending.

Common uses

The most common use is the "Contact Us" button on the official website page, where the subject is pre-filled (like "Inquiry from the website") to make it easier to sort incoming messages. Another common use is the "Send this page to a friend" link in articles, or a technical support link pre-filled with basic system information in the subject.

Link limits you need to know

A mailto link relies entirely on the presence of a mail program configured on the visitor’s device. Users who rely entirely on webmail (like opening Gmail from a browser without a dedicated program) may find that the link does not work as expected for them, or it may open a program selection window for a program they don’t have at all.

Frequently Asked Questions

What happens if the visitor does not have a properly set up mail program on their device?

A mailto link depends on a default mail program configured on the device. If none exists, the browser may show an error message or do nothing at all.

Can I add more than one recipient in the same link?

Yes, you can separate multiple addresses in the "To" field with a comma, and all addresses will appear as primary recipients.

Is the pre-filled text editable by the recipient?

Yes, exactly, the text and subject are just default values, and the person sending the message can modify them freely.

Is a mailto link safe and free of any security risk?

Yes, it is completely safe, because it is just a link that opens the local mail program and does not send any data to an external server.

Summary

A mailto link is a simple and quick way to facilitate communication with your website visitors, without any need for a complex contact form or additional programming code — one minute is enough to create a professional link ready to use anywhere on your site.
